概要

AutoPianoRenderは、ピアノの楽譜（PDF形式）を読み込み、最終的なマスタリング済みのWAVオーディオファイルとして出力するまでの一連の処理を完全自動化するコマンドラインツールです。

本システムは、光学楽譜認識（OMR）、MIDIデータの論理補正、サンプラーによる高音質レンダリング、およびPython内蔵DAWによるオーディオマスタリングという4つの独立したプロセスを1つのパイプラインとして統合しています。これにより、手作業によるDAWでの打ち込みや編集の手間を大幅に削減し、PDFから直接高品質のピアノ音源を生成することが可能です。

パイプラインのアーキテクチャ
本ツールは、以下の4つの段階を経てオーディオを生成します。また、各段階の中間ファイルは自動的に整理され、後戻りや部分的な手動修正が容易な設計となっています。

1. 光学楽譜認識 (Audiveris)
指定されたPDF楽譜に対し、Audiverisエンジンをバッチモードで実行して解析を行います。安定した大規模解析を確保するため、システム側でJavaに対して最大16GBのメモリを強制的に割り当てます。解析結果はMusicXMLフォーマットとして出力されます。

2. データ論理補正 (Music21)
生成されたXMLデータをMusic21ライブラリによって解析し、MIDIファイルへ変換する際の前処理を行います。この段階では、OMR特有の認識漏れによる「小節の長さ不足」を自動検知してリズムを補正するほか、強弱記号の無効化（音量均一化）や任意のBPMへのテンポ固定など、オーディオ出力に最適な状態への論理補正を対話形式で適用します。

3. オーディオレンダリング (sfizz)
補正済みのMIDIデータはsfizzエンジンに渡されます。ここでは、実機録音に基づく高品質なSFZ音源（Accurate Salamander Grand Piano）を使用し、サンプリングレート44.1kHzの非圧縮WAVファイルとして生音のレンダリングを実行します。

4. 自動マスタリング (Pedalboard)
レンダリングされた未加工のオーディオファイルに対し、Spotify社が開発したオーディオ処理ライブラリ「Pedalboard」を用いて最終的な音響調整を行います。不要な低音域をカットするハイパスフィルター、打鍵のアタック感を残しつつ音圧を整えるコンプレッサー、そして音の輪郭を損なわない繊細なリバーブ処理をプログラム内で適用し、クリアでメリハリのある音源（_mastered.wav）へと仕上げます。

動作環境とセットアップ
本ツールの実行には、Python環境および以下の外部ソフトウェアの配置が必要です。

実行環境のルートディレクトリに、以下の構造で各ソフトウェアを配置してください。

Audiveris （OMR実行ファイル群）

sfizz-1.2.3-win64 （レンダリングエンジン本体）

AccurateSalamanderGrandPianoV6.2beta2_48khz24bit （SFZ音源データ）

また、Pythonの依存ライブラリとして、あらかじめパッケージをインストールしておく必要があります。

music21 pedalboard soundfile pymupdf

使用方法
ルートディレクトリに存在する Score フォルダに、変換対象となるPDFファイルを配置してPythonスクリプトを実行します。コンソール上に検出されたPDFの一覧が表示されるため、任意の番号を入力して処理を開始してください。

処理が完了すると、自動生成される Completed フォルダ内に各楽曲ごとの専用ディレクトリが作成され、最終マスタリング済みのオーディオファイルおよびすべての中間データが整理されて保存されます。

手動補正ワークフロー（エラーリカバリ）
元となるPDFの画質や複雑な記譜により、Audiverisによる自動認識が不完全に終わる場合があります。本システムはこのような事態を想定し、ファイルの状態を検知して不要なプロセスをスキップするスマート・レジューム機能を備えています。

処理エラー等によりWAVの出力に不具合が生じた場合、ユーザーは生成された .omr プロジェクトファイルをAudiverisのGUI上で直接開き、認識漏れの箇所を手動でアサインし直すことができます。修正後、手動で .mxl ファイルを同ディレクトリにエクスポートしてから本スクリプトを再実行してください。システムは既存のXMLファイルを検知して第一段階（OMR解析）をスキップし、修正済みのデータを用いて残りの論理補正およびオーディオレンダリングをシームレスに再開します。
